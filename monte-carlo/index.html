Formula guide & model assumptions

Functions: min, max, abs, sqrt, round, floor, ceil, exp, log (natural logarithm), pow. Example: max(demand - inventory, 0). ^ means exponentiation. Names are case-sensitive.

Every uncertain input consumes one uniform draw per trial. Normal inputs are continuous and unbounded. Negative draws are retained; rounding or clipping requires an explicit output formula. Discrete probabilities must sum to 1. There are no correlated inputs or time steps in this version.

Models and comparisons autosave in this browser when storage is available. Download JSON for a portable backup. No model data is uploaded.
